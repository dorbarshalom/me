# Communication Language

- **Chat Language**: All chat communication, explanations, responses, and questions must remain in **English (EN)** at all times.
- **Multilingual Materials**: Even if user inputs, source code, UI strings, or reference materials are in Hebrew (HE) or another language, all conversation and chat responses must strictly be conducted in English.
